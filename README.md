## What is Voxly?
Voxly is an emotion-aware multilingual AI chatbot that detects your mood and responds accordingly in 7+ languages. Built from scratch as a real product, not a tutorial project.

## Features
- 🌍 7+ languages supported
- 🧠 Emotion detection — Voxly reads your mood and adapts
- 🎤 Voice input + output
- 💬 Chat memory across messages
- 🔌 Embed widget — one line of code to add Voxly to any website

## Tech Stack
- Node.js + Express
- Groq API (LLaMA 3.3 70B)
- Vanilla JS frontend
- Deployed on Render

## Run Locally
```
git clone https://github.com/qezzed10-cell/voxly.git
cd voxly
npm install
# Add your GROQ_API_KEY to .env
node index.js
```# voxly
